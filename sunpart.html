sunpart — disk partition layout planner

Start from whatever you have — a bare drive and its manufacturer's spec sheet, or the label line format already reports — and lay out slices a–h in megabytes. The translator turns a formatted capacity into a Sun label geometry, the planner packs everything on cylinder boundaries so overlaps are impossible, the checks tell you if the layout will boot and install, and the output is cylinder-aligned numbers you can type straight into the partition menu.

Spec translator — manufacturer's manual → Sun label

Leave heads and/or sec/track blank (auto) and sunpart picks values that waste the least — for a big SSD, auto heads is usually required to fit the 16-bit cylinder field.

Why only capacity matters: SCSI drives use zone bit recording — outer tracks carry more sectors — so the manual's cylinders × heads × sectors don't multiply out, and “bytes per track / per surface” figures are unformatted capacity you can never use. Take the formatted capacity (or guaranteed sector count) from the manual; the label geometry is just bookkeeping for the driver. Any hd × sec pair loses less than one cylinder to rounding, plus the two alternates. If the manual only quotes unformatted capacity, the formatted figure is typically 80–85% of it.

How this works: with an emulator you choose the disk, so sunpart sizes
    the image to hold the label's cylinders exactly — geometry × 512 bytes, zero waste.
    Emulating a known Sun disk is the smoothest path on SunOS 4.x: format
    recognizes it by name from format.dat, no manual geometry entry at all. The filename encodes the
    device: HD3.img = hard disk, SCSI ID 3. LUN and sector size are
    optional fields with the right defaults for hard disks (LUN 0, 512 bytes), so the short name is
    all you need on ZuluSCSI and BlueSCSI v2 alike (only the old BlueSCSI v1 firmware
    insisted on .hda). Sun expects the boot disk sd0 at target 3. Put the image in the SD card's root directory —
    and note FAT32 caps files at 4 GiB, so use exFAT for anything bigger.
